# cafe apart メニュー

店内用の印刷メニュー。色・フォント・ロゴはホームページ（`../cafe-apart-hp`）に合わせています。
`index.html` を開くと、2種類のメニューを選べます。

| フォルダ | 用途 | 内容 |
| --- | --- | --- |
| `register/` | レジ用 | A4 縦・2ページ。文字のみ |
| `book/` | ブック（客席用） | A4 縦・8ページ（中綴じ可）。フード・スイーツは種類と雰囲気ごとのグループで写真付き、ドリンクは文字のみ、T2 は1ページの特集。店舗情報は表紙の下。キッズは別メニューがあるため載せない |

## 印刷

各メニューの `index.html` をブラウザで開き、「印刷 / PDF保存」→ 用紙 A4・余白なし・背景のグラフィック ON。
（`npm start` でローカルサーバーも可）

## メニュー内容の更新

内容はホームページと同じ Google スプレッドシートが元データです。編集後に次を実行すると、両方のメニューに反映されます。

```sh
npm run sync                        # スプレッドシートから取得
node scripts/sync-menu.mjs foo.csv  # 手元の CSV から生成する場合
```

- `data/menu.csv` … 取得した CSV のスナップショット
- `data/menu-data.js` … 表示用データ（自動生成・直接編集しない）

## 写真（ブックメニュー）

```
photos/source/<名前>.jpg   元写真（ここを差し替える）
photos/crop.json           商品ごとのトリミング位置の調整
book/photos/<名前>.jpg     加工済み（自動生成）
```

- `npm run photos` で、元写真を **4:3 にトリミングし、色味（ホワイトバランス・明るさ・彩度）をそろえて** `book/photos/` に書き出します。
  料理の形や盛り付けは変えず、色と明るさだけを補正します。確認用の一覧が `photos/contact-sheet.jpg` にできます。
- `<名前>` はスプレッドシートの img 列のファイル名を小文字・ハイフン区切りにしたもの（例: `Egg Sandwich HALF.jpg` → `egg-sandwich-half.jpg`）。
- **撮り直した写真の差し替え**: 同じ名前で `photos/source/` に上書きして `npm run photos`。
- 写真が見切れる・寄りすぎる場合は `photos/crop.json` で `x` `y`（切り抜く中心、0〜1）と `zoom`（1 = 最大範囲、大きいほど寄る）を調整。
- 新しい商品に写真を付ける: スプレッドシートの img 列にファイル名を入れ、同じ名前（slug 化後）で `photos/source/` に写真を置く。
- 今の写真は、HP の git 履歴から最も解像度の高い版を取り込んだもの（`npm run photos:import`）。

## レイアウトの調整

- 印刷メニューに出さない品目: 各 `*.js` の `HIDDEN_TITLES`（例: 頑張るアルバイトさん）
- 別商品として載せず「〜に変更可能」と書く品目: 各 `*.js` の `VARIANTS`（例: カレーのバゲット。価格差は自動で「同価格」「+¥100」などと表示）
- レジ用: どのカテゴリをどのページ・列に置くか → `register/index.html` の `data-sections`、見出し → `register/menu.js` の `SECTIONS`
- ブック: ページ構成・グループ分け・列数 → `book/book.js` の `PAGES`（新商品はグループに入れるまで「その他」に出る）
- どちらも、ページに収まらない場合は自動で文字（ブックは先に写真の高さ）を縮めて収めます
- T2 / Kids は共通価格を見出しに出し、各品目の価格は共通価格と違う場合のみ表示
